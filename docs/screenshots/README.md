# Thermal Watch screenshot plan

This directory contains approved screenshots captured from the current public Thermal Watch build.

Current screenshots:

- `main-dashboard.png`
- `incident-history.png`
- `ask-thermal-watch.png`

An additional Trends or Maintenance screenshot may be added later when a suitable retained-data view is available.

Before adding an image:

1. Capture the real packaged application, not a design mockup.
2. Review hardware identifiers, process names, window titles, workloads, timestamps, reports, and exported data for private information.
3. Prefer representative evidence without implying universal sensor coverage or proven workload causation.
4. Confirm the screenshot matches the current public release and contains no unrelated desktop content.
5. Optimize the image without altering the measurements or application UI it depicts.

The main-dashboard screenshot is also the preferred basis for a future GitHub social preview: a 1280×640 image using the real dark/orange interface, Thermal Watch branding, and the subtitle “Windows Thermal & System Intelligence.”
